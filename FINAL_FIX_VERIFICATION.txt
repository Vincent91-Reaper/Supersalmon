PROBLEM:
- metadata["year"] could be None when years list empty
- RED requires valid integer for remaster_year
- None value causes validation error

ROOT CAUSE:
```python
if years:
    metadata["year"] = max(set(years), key=years.count)
# If years is empty, metadata["year"] stays None!
```

SOLUTION:
```python
if years:
    metadata["year"] = max(set(years), key=years.count)

if not metadata["year"]:
    # Try date field
    if dates:
        year_match = re.search(r'(\d{4})', date_str)
        if year_match:
            metadata["year"] = int(year_match.group(1))
    
    # Last resort: current year
    if not metadata["year"]:
        metadata["year"] = datetime.now().year
```
