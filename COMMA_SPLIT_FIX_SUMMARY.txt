"The retagging feature still doesn't work correctly. In the example above 
'Celsius, Tripped - An1x6578910 (2025)', track 1 is performed/contributed 
by both Celsius and Tripped but Brucelee94 retags its artist to only 'Celsius'"

PROBLEM:
--------
- Track 1 has TWO performers: Celsius AND Tripped
- Qobuz provides: performer = "Celsius, Tripped" (comma-separated string)
- Code was treating this as a SINGLE artist
- Result: Only "Celsius" was tagged, "Tripped" was missing

ROOT CAUSE:
-----------
File: brucelee94/tagger/sources/qobuz.py
Method: _collect_track_artists()

OLD CODE (WRONG):
    performer = safe_get(track, ["performer", "name"])
    if performer:
        artists.append((performer, "main"))  # ← Added entire string as one artist

SOLUTION:
---------
NEW CODE (CORRECT):
    performer = safe_get(track, ["performer", "name"])
    if performer:
        # Split comma-separated performers (e.g., "Celsius, Tripped")
        performer_names = [p.strip() for p in performer.split(",") if p.strip()]
        for performer_name in performer_names:
            artists.append((performer_name, "main"))

HOW IT WORKS:
-------------
1. Input: performer = "Celsius, Tripped"
2. Split: ["Celsius", " Tripped"]
3. Strip: ["Celsius", "Tripped"]
4. Add each:
   - ("Celsius", "main")
   - ("Tripped", "main")
