# Deezer Label Field Fix - Summary

## User Issue
User reported error when scraping metadata from Deezer URL:
"Unexpected scrape error: expected string or bytes-like object, got 'tuple'"
URL: https://www.deezer.com/en/album/868256782

## Problem
The parse_release_label() method in deezer.py was passing soup["label"] 
directly to parse_copyright(), but the Deezer API sometimes returns the 
label as a dict/object instead of a string, causing a type error in regex 
operations.

## Root Cause
- Deezer API returns label in multiple formats:
  1. String: "Label Name"
  2. Dict: {"id": 123, "name": "Label Name"}
- parse_copyright() expects string, uses re.search()
- When dict/tuple passed, regex fails with type error

## Solution
Modified parse_release_label() to handle different label formats:

```python
def parse_release_label(self, soup):
    label = soup.get("label")
    # Handle different label formats from Deezer API
    if isinstance(label, dict):
        label = label.get("name", "")
    elif not isinstance(label, str):
        label = str(label) if label else ""
    return parse_copyright(label)
```

## How It Works
1. Check if label is dict → extract "name" field
2. Check if not string → convert to string
3. Pass string to parse_copyright() → no error
