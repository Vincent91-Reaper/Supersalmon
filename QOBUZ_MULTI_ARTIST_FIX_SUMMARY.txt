Album "Celsius, Tripped - An1x6578910 (2025)" from Qobuz has 2 main artists

ROOT CAUSE
----------
In brucelee94/tagger/sources/qobuz.py:
- _collect_track_artists() was adding ALL album main artists to EVERY track
- Track's performer was added as "guest" if different from album artists
- Qobuz provides track-level performer data that was being ignored

SOLUTION
--------
Modified _collect_track_artists() in qobuz.py:
1. Check if track has its own performer data
2. If yes: Use track performer as main artist
3. If no: Fall back to album main artists
4. Preserve all other artist detection (featured, title parsing, etc.)

CODE CHANGE
-----------
OLD (WRONG):
  # Always add album main artists to every track
  for artist_name in main_artist:
      artists.append((artist_name, "main"))
  
  # Add track performer as guest
  if performer:
      artists.append((performer, "guest"))

NEW (CORRECT):
  # Check track performer first
  if performer:
      # Use track performer as main artist
      artists.append((performer, "main"))
  else:
      # Fall back to album main artists
      for artist_name in main_artist:
          artists.append((artist_name, "main"))
